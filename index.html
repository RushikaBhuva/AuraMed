Technical Capabilities & System Answers

Direct answers for technical review questions (Push Notifications, Payments, CI/CD, Security, Cloud Deployment, Backups)

1. Push Notifications & SMS

Solution: Firebase Cloud Messaging (FCM) integrated with Flutter front-end, paired with Twilio SMS API for fallback appointment/medication reminders. Microservices queue via Celery / Redis for high-throughput scheduled dispatch.

2. Subscription & Payment Integrations

Solution: Stripe Subscriptions & In-App Purchases (RevenueCat / Apple App Store & Google Play Billing). Multi-tier plans (Free PHR tier vs Premium AI Health Assistant). Secure Webhooks handling automatic plan upgrades and renewals.

3. Docker & CI/CD Pipeline

Solution: Automated GitHub Actions workflow building multi-stage Docker images. Automated pytest unit/integration testing, SonarQube code scan, pushing images to AWS ECR, and zero-downtime deployment via Kubernetes (EKS) / AWS ECS Fargate.

4. Cloud & Production Deployment

Solution: Production setup on AWS (or GCP): FastAPI backend running behind Nginx / AWS ALB, PostgreSQL (RDS Aurora) with Multi-AZ failover, Redis ElastiCache for session & OCR task caching, AWS S3 with KMS encryption for document storage.

5. API & Application Security

Solution: OAuth2 + JWT authentication, HTTPS/TLS 1.3 enforced, AES-256 KMS encryption for files, PostgreSQL Row Level Security (RLS) to enforce strict patient data isolation, OWASP top 10 compliance & rate limiting.

6. Monitoring, Backups & Support

Solution: Prometheus & Grafana dashboard for API latency & OCR inference times, Sentry for real-time error tracking, Automated daily DB backups with 30-day point-in-time recovery (PITR), 99.9% uptime SLA design.
